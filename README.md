# 课堂智控台

仿「远程看班神器」的课堂管理网页：远程叫人、纪律、作业、随机点名、计时。

布局采用**左侧竖向导航 + 右侧大屏实况**，与原文顶部 Tab 网格布局不同。

## 启动

```bash
cd classroom-hub
npm install
npm run dev
```

浏览器打开终端提示的本地地址。教室一体机切到「教室大屏」模式；手机/办公室电脑用「手机遥控」。

## 功能

| 模块 | 说明 |
|------|------|
| 远程叫人 | 单击播报；多选排队呼叫；可改播报文案 |
| 纪律管理 | 违纪/表扬记录，今日榜单 |
| 作业布置 | 未完成/已完成双栏，完成率实时统计 |
| 随机点名 | 滚动抽取，全班/未点到，避免重复 |
| 计时工具 | 倒计时预设 + 秒表记圈 |
| 班级设置 | 名单增删、CSV 导入导出、房间口令 |

数据保存在浏览器 localStorage。同浏览器多标签可通过 storage 事件同步实况。
