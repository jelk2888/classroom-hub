  看班智控台 Pro（classroom-pro）源码使用说明

一、项目是什么
--------------------------------------------------------------------------------
看班智控台 Pro 是一套班级课堂管理系统：教师端网页发指令，教室大屏同步显示
叫人、点名、计时、公告、作业、纪律、积分等。数据存 SQLite，实时通道用
WebSocket / SSE。

目录结构（源码根目录 classroom-pro）：

  client/           教师端 + 大屏前端（React + Vite）
  server/           API 与静态资源服务（Node.js + Express + SQLite）
  board-desktop/    教室一体机「教室大屏智控」Electron 桌面端
  deploy/           群晖 / Web Station 打包与上传说明
  FEATURES.md       功能清单
  README.md         简要说明

演示账号：
  班级  DEMO01 / 123456
  管理  admin  / admin123


二、环境要求
--------------------------------------------------------------------------------
  - Windows 10/11 或 Linux（NAS 上常用 Node 容器）
  - Node.js 18 及以上（建议 LTS）
  - 打包一体机安装程序时：本机需有 Python 3，以及 .NET Framework 自带的 csc.exe
    （Windows 一般已具备）


三、本地开发启动
--------------------------------------------------------------------------------
1）启动后端

  cd classroom-pro/server
  npm install
  npm run dev

  默认 API：http://127.0.0.1:3789
  数据库文件：server/data/classroom.db（首次自动创建）

2）启动前端

  cd classroom-pro/client
  npm install
  npm run dev

  默认前端：http://127.0.0.1:5174
  同局域网手机可访问：http://电脑局域网IP:5174

3）浏览器打开教师端，用 DEMO01 / 123456 登录。


四、一体机「教室大屏智控」
--------------------------------------------------------------------------------
用途：教室电脑/一体机安装后，平时右侧显示「今日课表」，不置顶，不挡课件；
教师端发任务时再展开大屏。

窗口行为简述：
  - 登录设置页：「最小化」灰色不可用
  - 登录成功：进入右侧「今日课表」待命（不最大化、不置顶）
  - 右侧课表时：「最小化」灰色；点「最大化」→ 展示完整大屏
  - 大屏展示中：可点「最小化」收回右侧课表
  - 有教师任务时：自动展开大屏

打包便携版：

  cd classroom-pro/board-desktop
  npm install
  python pack-portable.py

  输出：board-desktop/dist-exe/教室大屏智控/

打包安装程序（单文件 EXE，可供网页下载）：

  cd classroom-pro/board-desktop
  python pack-installer.py

  输出：
    board-desktop/dist-exe/教室大屏智控-安装程序.exe
    并自动复制到：
      server/downloads/
      client/public/downloads/

安装程序会安装到：
  %LOCALAPPDATA%\Programs\教室大屏智控\
  并创建桌面与开始菜单快捷方式。

首次运行填写：服务器地址（局域网或公网）、班级代码、密码。
配置保存在一体机本地 board-config.json。


五、网页登录后下载安装程序
--------------------------------------------------------------------------------
教师用浏览器登录成功后，首页顶栏有按钮：

  「下载一体机安装程序」

对应地址：

  /downloads/教室大屏智控-安装程序.exe

服务端从 server/downloads/ 提供文件。若提示没有安装包，请先在开发机执行
pack-installer.py，再把生成的 EXE 放到 server/downloads/ 后重新上传站点。


六、群晖 Web Station / Node 站点部署
--------------------------------------------------------------------------------
1）在开发机打包上传目录：

  cd classroom-pro/deploy/synology/webstation
  powershell -ExecutionPolicy Bypass -File .\pack-webstation.ps1

  生成：deploy/webstation-upload/classroom-pro/

2）将该目录整体上传到 NAS，例如：

  /volume1/web/classroom-pro/

3）按 Web Station / 容器说明安装依赖并启动 Node：

  cd /volume1/web/classroom-pro
  npm install --omit=dev
  # 或按站点面板配置启动命令：node server/index.js

4）确保目录可写（SQLite、上传）：

  server/data/
  server/downloads/   （放一体机安装程序）

更细的群晖步骤见同目录 README-WebStation.md 与
deploy/synology/SYNOLOGY-部署说明.md。


七、双端课堂用法
--------------------------------------------------------------------------------
1）教师手机或电脑：浏览器打开站点 → 登录班级（教师端）
2）教室一体机：
   - 推荐：安装「教室大屏智控」，登录同一班级，右侧课表待命
   - 或网页：/?mode=desktop 本机登录进大屏
3）教师端「打开教室大屏」/ 发叫人、点名、计时、公告等 → 大屏实时同步
4）侧栏「大屏：在线」表示教室端已连上；外出可用管理后台配置的公网回退地址


八、常见功能入口（教师端登录后）
--------------------------------------------------------------------------------
  呼叫 / 点名 / 计时 / 纪律 / 作业 / 日志 / 值日 / 积分商城 / 宠物
  周课表、座位表、摄像头喊话、设置（名单导入、公告、备份、改密）

公告：设置里可发布；顶栏可「清除公告」。公告存在服务器数据库，不是客户端写死。


九、源码二次开发提示
--------------------------------------------------------------------------------
  - 前端改完需：cd client && npm run build
  - 再执行 pack-webstation.ps1 更新上传包
  - 改 board-desktop/main.cjs 后需：pack-portable.py → pack-installer.py
  - API 路由在 server/index.js；实时在 server 的 WebSocket 相关模块
  - 不要把含真实密码的 board-config.json、classroom.db 提交到公开仓库


十、许可与分享
--------------------------------------------------------------------------------

按校内规范使用；对外再分发时请自行确认数据合规与账号安全
