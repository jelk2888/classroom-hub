看班智控台 Pro — 本文件夹可单独使用
================================

把整个「classroom-pro」文件夹复制到任意位置即可，不需要上级目录，也不需要源码。

一、在 Windows 上直接打开网站
--------------------------------
1. 电脑已安装 Node.js 18 或更高版本（https://nodejs.org/）
2. 双击本目录里的「一键启动网站服务.bat」
3. 浏览器会打开 http://127.0.0.1:3789/
4. 登录：班级 DEMO01 / 123456 ，管理 admin / admin123
5. 关闭黑色窗口即停止服务
6. 班级数据在 server\data\classroom.db ，换电脑时连同 data 文件夹一起复制，不要删

手机和教室电脑访问：看启动窗口里打印的局域网地址，例如 http://192.168.x.x:3789/

二、教室一体机
--------------------------------
安装包已在本文件夹内：
  server\downloads\教室大屏智控-安装程序.exe
教师登录网站后，首页也可以下载同一安装包。
安装后登录同一班级。摄像头默认关闭，由教师端再打开。

三、放到群晖 Web Station
--------------------------------
1. 把本文件夹整份上传到群晖，例如 /volume1/web/classroom-pro/
2. 文档根目录选这个文件夹（里面能直接看到 package.json、server、client\dist）
3. 执行命令填 npm start ，端口按套件要求（程序会读环境变量 PORT）
4. 读取超时建议 86400（否则 WebSocket 容易断）
5. 已有网站时，只覆盖程序文件，不要删除服务器上的 server\data

四、本文件夹里有什么
--------------------------------
  package.json          启动入口
  client\dist\          已构建好的网页，不用再编译
  server\               接口程序；server\node_modules 为运行依赖
  server\downloads\     一体机安装包
  一键启动网站服务.bat  Windows 双击启动
