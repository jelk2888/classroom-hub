# 看班智控台 · 能力对照与本次升级

对照 [小橙看班](https://kb.inartview.com/) 官网能力，结合本校「教师浏览器 + 教室大屏/EXE」架构。

## 已具备 / 本次增强

| 能力 | 小橙 | 看班智控台 |
|------|------|------------|
| 远程通知 / 叫人上屏 | ✓ | ✓ 远程叫人 + TTS |
| 实时摄像头 / 喊话 | ✓ | ✓ 摄像头喊话（WebRTC） |
| 计时器 | ✓ | ✓ |
| 随机抽取 | ✓ | ✓ 随机点名 |
| 班级课表 | ✓ | ✓ **周课表**（大屏右侧竖排当天） |
| 桌面时钟 | ✓ | ✓ 大屏顶部时钟 |
| 托盘待命少打扰 | ✓ 一体机客户端 | ✓ **EXE 托盘最小化，有任务再弹** |
| 座位相关 | — | ✓ **座位编排**（行列/点选/拖换，大屏可看） |
| 纪律 / 作业 / 积分 / 值日 | — | ✓ 已有 |

## 暂未并入（可后续做）

- 全校集控关机锁屏、校内直播、定时录像回放（偏校园版平台）
- 微信小程序端（当前教师端保持浏览器，便于校内部署）
- 文件秒传、考勤人脸等需额外硬件/云服务的能力

## 部署建议

- **教师**：浏览器访问站点（如 `http://test.zjjdg.top:5666/`）
- **教室一体机**：安装 `board-desktop` 打包的 EXE，`BOARD_URL` 指向站点 `/?mode=desktop`
- 网页大屏仍可用 `?mode=board`（需已登录同班会话）
